# 2. ОПИСАНИЕ ПРОЕКТА

Название: MetalCalc.

Тип продукта: веб-приложение для проектирования металлических конструкций и расчёта их стоимости.

Основная идея:

Пользователь открывает приложение, создаёт новый проект и получает рабочую область, похожую на упрощённую CAD-программу.

В рабочей области он может рисовать металлические конструкции при помощи линий, задавать точные размеры в миллиметрах и назначать каждой линии определённый вид профильной трубы.

Например:
- 20×20 мм;
- 40×20 мм;
- 40×40 мм;
- 60×30 мм;
- 80×40 мм.

Пользователь заранее создаёт каталог материалов и указывает стоимость каждого профиля за погонный метр.

Также пользователь указывает стоимость покраски и сварочных работ.

После создания или изменения конструкции приложение автоматически пересчитывает:
- общую длину металла;
- количество каждого вида профиля;
- стоимость металла;
- стоимость покраски;
- стоимость сварки;
- общую стоимость конструкции.

В приложении должны присутствовать два режима отображения:

1. Двумерное черчение (2D).
2. Трёхмерная визуализация (3D).

Оба режима должны использовать одну общую модель конструкции.

# 7. ЕДИНАЯ МОДЕЛЬ ДАННЫХ

Создай центральную систему хранения геометрии конструкции.

Не допускай независимого существования 2D-чертежа и 3D-модели.

Все элементы должны храниться в единой модели.

Каждый элемент конструкции должен содержать:

- Уникальный ID.
- Тип элемента.
- Координаты начала.
- Координаты конца.
- Ссылку на профиль.
- Длину.
- Цвет.
- Тип соединения.
- Дополнительные параметры.

Пример логической структуры:

```ts
interface ConstructionElement {
  id: string;
  type: "beam";
  start: {
    x: number;
    y: number;
    z: number;
  };
  end: {
    x: number;
    y: number;
    z: number;
  };
  profileId: string;
  color?: string;
}
```

Это пример базовой структуры. Расширь её при необходимости.

Все координаты и размеры храни в миллиметрах.

Не храни вычисляемые значения как единственный источник истины, если их можно надёжно получить из геометрии.

# 10. МОДУЛЬ АВТОМАТИЧЕСКОГО РАСЧЁТА

Это главная коммерческая функция приложения.

Создай отдельный модуль расчётов, не смешивай его с интерфейсом.

Все расчёты должны автоматически обновляться при изменении конструкции или цен.

## 10.1. Расчёт металла

Для каждого профиля суммируй длины всех элементов, использующих этот профиль.

Формула:

Стоимость металла = Общая длина профиля в метрах × Цена за метр.

Пример:

Профиль 40×40×2:
Общая длина 5 метров.
Цена 450 рублей за метр.

Стоимость: 2250 рублей.

Профиль 60×30×2:
Общая длина 3 метра.
Цена 500 рублей за метр.

Стоимость: 1500 рублей.

Общая стоимость металла: 3750 рублей.

## 10.2. Расчёт покраски

Пользователь указывает цену покраски за погонный метр.

Формула:

Стоимость покраски = Общая длина окрашиваемых элементов × Цена покраски за метр.

Предусмотри возможность исключить отдельные элементы из покраски.

В будущем добавь расчёт по площади поверхности, но в первой версии используй погонные метры.

## 10.3. Расчёт сварки

Реализуй два способа:

Способ 1:
Цена за погонный метр сварного шва.

Способ 2:
Цена за одно соединение.

Пользователь должен иметь возможность задать тариф.

Длина сварного шва должна задаваться вручную либо рассчитываться по геометрии и параметрам конкретного соединения.

Не приравнивай автоматически длину шва к длине трубы.

## 10.4. Итоговая смета

Смета должна показывать:

- Каждый используемый профиль.
- Количество метров каждого профиля.
- Цену за метр.
- Стоимость каждого профиля.
- Стоимость покраски.
- Количество сварных соединений.
- Длину сварных швов, если она известна.
- Стоимость сварки.
- Общую стоимость.

Предусмотри возможность настройки валюты.

В первой версии можно использовать рубли по умолчанию.

Все денежные вычисления выполняй с контролем точности округления.
