# MetalCalc

**MetalCalc** — веб-приложение для проектирования металлоконструкций из профильных труб (навесы, каркасы, фермы, стеллажи, столы, ворота и др.), 2D-черчения в трёх ортогональных проекциях, 3D-просмотра с подрезкой стыков и автоматического расчёта стоимости с экспортом в Excel и PDF.

---

## Зачем и что умеет

Приложение объединяет в одном окне чертёж, 3D-модель и живую смету:

- **2D-черчение в трёх проекциях (`XY`, `XZ`, `YZ`)**
  - Режимы «3 вида» (главный план `XY` + виды спереди `XZ` и сбоку `YZ`) и «1 вид (`XY`)».
  - Инструменты: выбор, линия, прямоугольник, ломаная, сдвиг, копирование, изменение размера, удаление.
  - Магнитные привязки к сетке, вершинам, серединам, ортогональность (`Ortho`), редактирование за ручки вершин.
  - Ввод балок по точным координатам `X / Y / Z` (в миллиметрах) и настройка параметров выбранной трубы.
- **3D-визуализация (`Three.js` / `@react-three/fiber`)**
  - Реалистичное отображение профильных труб с заданным сечением и цветом.
  - Автоматическое определение стыков и подрезка концов (`miter` — на ус, `butt` — встык со сквозной и примыкающей балкой, `none` — по осям).
  - 3D-манипулятор перемещения вдоль осей `X`, `Y`, `Z`, рисование на рабочих плоскостях, пресеты камер (`Изометрия`, `Сверху`, `Спереди`, `Сбоку`).
- **Адаптация под ПК, ноутбуки и планшеты**
  - На планшетах (`< 1024px`) боковые панели убираются в выдвижные шторки, проекции `XZ` и `YZ` перестраиваются под главный вид `XY`, а 2D/3D-холсты поддерживают жесты одним пальцем/стилусом, pinch-zoom и панорамирование двумя пальцами.
  - На ноутбуках и десктопах любую из боковых панелей можно свернуть кнопками в шапке.
- **Каталог профилей и калькулятор сметы**
  - Отдельные настройки размеров (`Ш × В × толщина стенки`), цены за погонный метр, типа сечения (прямоугольная/квадратная труба) и цвета.
  - Подсчёт расхода металла, покраски (за метр или по площади), резки, сварки (по длине швов или по периметру сечения) и отхода.
  - Экспорт спецификации и чертежа в **Excel (`.xlsx`)** и **PDF**.
- **Аккаунты и полная изоляция проектов**
  - Регистрация и вход по email + паролю (проверка надёжности пароля + подтверждение почты 6-значным кодом через SMTP) или через **Яндекс ID**.
  - Неавторизованный пользователь со страницы редактора `/editor` перенаправляется на `/login`.
  - Проекты, каталог профилей и настройки каждого пользователя хранятся в SQLite изолированно.

## Страницы приложения

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная страница с описанием возможностей и переходом в редактор |
| `/editor` | Рабочее пространство: 2D/3D-редактор, каталог профилей, стыки и смета (требует авторизации) |
| `/projects` | Список проектов пользователя (создание, открытие, дублирование, переименование, удаление) |
| `/settings` | Настройки сетки, привязок, валюты и коэффициентов расчёта сметы |
| `/login` | Вход по email/паролю или через Яндекс ID |
| `/register` | Регистрация с оценкой надёжности пароля и подтверждением почты по коду |

## Структура проекта

```text
├── app/                     # Next.js App Router (страницы и API-роуты)
│   ├── api/                 # REST API: auth, projects, profiles, export (excel/pdf)
│   ├── editor/              # Страница редактора /editor
│   ├── login/, register/    # Авторизация и регистрация
│   ├── projects/            # Менеджер проектов
│   └── settings/            # Настройки расчётов и сетки
├── components/              # UI-компоненты интерфейса
│   ├── auth/                # Формы входа, регистрации, OAuth-кнопки, бейдж аккаунта
│   ├── common/              # Модальное окно сметы и синхронизация темы (светлая/тёмная)
│   ├── editor/              # Каркас редактора и переключатель 2D/3D
│   ├── landing/             # Главная страница
│   ├── layout/              # Верхняя панель инструментов и нижняя строка состояния
│   ├── panels/              # Левая панель инструментов/профилей и правый инспектор
│   ├── projects/            # Интерфейс списка проектов
│   └── settings/            # Интерфейс настроек
├── features/                # Доменная логика и холсты
│   ├── calculator/          # Панель расчёта стоимости
│   ├── drawing/             # 2D-движок на Konva (3 проекции, привязки, размеры, touch/pinch)
│   ├── export/              # Клиентские и серверные генераторы Excel/PDF
│   ├── joints/              # Поиск стыков и панель управления подрезкой/сваркой
│   ├── profiles/            # Модальное окно каталога профилей и стандартные профили
│   └── visualization/       # 3D-сцена на Three.js, геометрия балок со скосами, 3D-гизмо
├── lib/                     # Серверная и математическая база
│   ├── auth/                # Хеширование паролей (scrypt), сессии, OAuth, SMTP-клиент
│   ├── calculations/        # Расчёт длин, массы, покраски, сварки и сметы
│   ├── db/                  # SQLite-база (встроенный node:sqlite) и репозитории
│   ├── export/              # Серверная сборка .xlsx (exceljs) и .pdf (pdfmake)
│   ├── geometry/            # 2D/3D-математика, привязки, пересечения, подрезка стыков
│   └── validation/          # Zod-схемы форм и API
├── store/                   # Zustand-сторы (проект, авторизация, тема, UI-панели)
├── tests/                   # Модульные и интеграционные тесты (Vitest)
└── data/                    # Папка с файлом БД SQLite (создаётся автоматически)
```

## Стек технологий

- **Фреймворк**: Next.js 16 (App Router, Turbopack), React 19, TypeScript
- **Стили**: Tailwind CSS v4, `lucide-react`
- **2D / 3D графика**: `konva` + `react-konva`, `three` + `@react-three/fiber` + `@react-three/drei`
- **Состояние и валидация**: `zustand`, `react-hook-form`, `zod`
- **База данных**: встроенный модуль `node:sqlite` (`DatabaseSync`, режим WAL) — без внешних СУБД и нативной сборки
- **Экспорт**: `exceljs`, `pdfmake`
- **Тесты**: `vitest`

## Локальный запуск (для разработки)

> Требуется **Node.js 22.5+** (рекомендуется **Node.js 24 LTS**), так как используется встроенный `node:sqlite`.

```bash
npm install
cp .env.example .env
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

> Если `SMTP_*` в `.env` не заполнен, в `dev`-режиме 6-значный код подтверждения почты выводится в консоль сервера и отображается в подсказке на форме.
